# # 未命名白板

# 怎么使用 — 从这里开始

这张白板就是你的思考工作台,结构即思路:上层是高阶概览,展开子节点看细节,能折叠、能移动、能在节点上直接提问。

**三条路径,选你想学的:**
- 想操作白板本身(建节点、拖拽、上色)→ 看「白板/思维导图操作」
- 想让我帮你干活(研究、梳理、生成)→ 看我「如何与你协作」
- 想知道整个工具能做什么 → 看「工作区概览」

> 建议从上往下走一遍,几分钟就能上手。

# 快速上手：用一个实测练一遍

建议选一个真实主题走一遍完整流程,上手最快。例如:
「我想整理一篇 X 的文献综述」→ 看我怎么先澄清方向、再做研究、最后把结论排成白板结构。


# 白板 / 思维导图操作

如何在这个白板上组织内容。

# 新建与命名节点

- 在白板上点 + 号或双击空白处即可新建节点
- 给每个节点写一个「主题句」作为标题,细节放到子节点里
- 技巧:一个节点只讲一件事,把多层内容拆成父子层级,结构就是你的思路

# 移动、删除与整理

- 拖拽即可把节点换到其它父节点下,重组结构
- 删除节点会连同其子节点一起删(可保留子树)
- 随时整理:把散落的零碎拖进新的分组节点,白板越理越清晰

# 层级与折叠

- 父子节点体现包含关系:高层是概览,下层是细节
- 展开/折叠子节点,随时聚焦当前关心的那一支,不被打扰
- 需要比较的并列选项 → 放成同级(兄弟)节点,一眼看清优劣势

# 颜色标注与文件挂载

- 需要区分优先级、状态或类别时,可给节点标注颜色(如重点/待办/完成)
- 可以把 PDF、论文、文档等素材「挂」到节点上,作为该分支的依据材料,点开即可回看

# 在节点上直接回答

很多决策点是「问题节点」:旁边会显示待你回答的问题,点一下选项即可。
你的每一次回答都会让整张白板向前推进、内容随之更新——这就是协作的核心。

# 如何与我协作

让我当你的思考伙伴,而不只是提问机器。

# 直接向我提问

把问题告诉我,我会:
- 先澄清 1–3 个关键问题,确保方向对
- 直接查证:需要事实时先搜索、再给结论,每个事实都标注来源
- 把**答案做成白板**:结构化的节点,而不是一段文字

# 委托我做研究

- 说「调研 X 市场」「查一下 Y 的最新进展」→ 我会多路搜索、交叉核验、综合成结论
- 适合多角度、需要比对和归纳的复杂课题;简单查证则一步到位
- 关键来源会作为节点放到白板上,你可以点开逐一核实

# 生成信息图 / 幻灯片 / 文档
- 一句话描述需求,可交付在白板视图、演示文稿(幻灯片)或 Markdown 文档
- 我只在你说清楚用途、受众与偏好后才动手,避免做偏

# 复盘与推进
- 我偏好「边做边问」:重要节点旁有选项供你拍板,而不是等我猜
- 你的回答会贯穿到整张白板——我会追问新问题、修正方向,直到成果可落地

# 整个工作区概览

这个工具能放哪些东西、扮演哪些角色。

# 几种载体

- **白板(Mindmap)**:结构化思维、头脑风暴、梳理关系的主力
- **幻灯片(Slides)**:把结论做成可展示的页卡
- **文档/Doc**:完整叙述、报告、论文草稿
- **研究(Academic)**:下载并引用真实论文 PDF

# 来源与可核验性
- 我引用的每个事实都带出处,标注在内容旁,可点击回原文件或网页——不编造
- 用到的论文/网页/文档会作为独立节点放在白板上,方便你逐个核实
